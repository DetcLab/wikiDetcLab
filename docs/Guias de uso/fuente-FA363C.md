# Fuente FA363C

La **fuente de alimentación Proxmax FA363C** permite suministrar **voltaje y corriente regulables** para circuitos electrónicos. Esta guía explica cómo usarla de manera segura y efectiva.

## 1. Componentes principales

- **Pantalla digital:** muestra voltaje y corriente de salida.  
- **Mandos de ajuste:**  
  - **Voltaje:** regula la tensión de salida.  
  - **Corriente:** limita la corriente máxima suministrada.  
- **Interruptor de encendido/apagado:** controla la alimentación principal.  
- **Terminales de salida:**  
  - **Rojo:** positivo (+)  
  - **Azul:** negativo (-)  
  - **Amarillo:** tierra  
- **Protecciones internas:** evita sobrecorriente o cortocircuitos. 

> ⚠️ **Precaución:** El conector amariillo es la tierra de distribución del edificio, no la de nuestro circuito"

## 2. Ajuste de parámetros

1. Enciende la fuente con el interruptor principal.  
2. Ajusta el **voltaje** al valor deseado usando el mando correspondiente.  
3. Ajusta el **límite de corriente** según las necesidades del circuito.  
4. Observa en la pantalla que los valores se estabilicen antes de conectar la carga.  

## 3. Conexión al circuito

1. Conecta el terminal **rojo** al punto positivo del circuito.  
2. Conecta el terminal **negro** al punto negativo o masa del circuito.  
3. Usa cables adecuados para la corriente que vas a suministrar.  
4. Asegúrate de que las conexiones sean firmes y seguras.  

## ⚠️ Consejos de seguridad

- Nunca excedas la tensión o corriente máxima de la fuente.  
- No toques los terminales metálicos mientras la fuente esté encendida.  
- Comprueba siempre la polaridad antes de conectar el circuito.  
- Desconecta la fuente antes de modificar el circuito o cambiar conexiones.
